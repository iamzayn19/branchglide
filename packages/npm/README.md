# branchglide

Preview any Git branch. Share it without deploying.

```bash
npm install -g branchglide
branchglide --version
```

This package is a thin launcher around the canonical Ruby implementation
of Branchglide. **It requires a system Ruby (>= 3.0) on PATH** — it does
not bundle a portable Ruby runtime. If `branchglide` fails with "no Ruby
interpreter found," install Ruby (e.g. via your OS package manager,
[rbenv](https://github.com/rbenv/rbenv), or [asdf](https://asdf-vm.com/))
and re-run.

Full documentation: https://github.com/iamzayn19/branchglide
